# Frontend Angular Application
# This directory contains the Angular frontend implementation

## Structure
- app/ - Main Angular components and services
  - components/ - UI components
    - upload/ - File upload component
    - preview/ - AI analysis preview component
    - layout-editor/ - Report layout editor component
  - services/ - Angular services
    - file.service.ts - File upload service
    - report.service.ts - Report API service
  - app.component.* - Root component
  - app.module.ts - Main module

## Features
- Multi-step wizard UI
- Real-time file upload
- AI-powered design analysis preview
- Interactive layout editor
- Report compilation and export

## Running the Application
```bash
npm install
ng serve
```
Then navigate to `http://localhost:4200`
